# Motion specification

Use natural document scroll as the authoritative position. Lenis interpolates desktop wheel input using the GSAP ticker. Native anchors, keyboard navigation, scrollbars and touch remain available. Reduced-motion users get immediate navigation. Preserve scroll restoration and disable continuous motion when outside the viewport.

- Hero. An entrance resolves two offset rows into place. Fine-pointer motion offsets each plate by depth and returns to neutral on exit.
- Services and work. A sticky viewport translates actual section travel into a bounded progress value. Active metadata changes with the foreground item. Moving backwards uses the same mapping.
- Wordmark. The front, side and bevel establish depth. Angle and wave phase follow scroll. Keep a visible wordmark when WebGL is unavailable.
- Process. The horizontal travel is the track's rendered width minus the visible width. Recompute after resizing and font loading. Narrow screens must expose all five stages.
- Studio and studies. Horizontal drags select adjacent cards and decelerate to a stable index. Buttons and keyboard provide an equivalent input.
- Contact. Nearby characters react more than distant characters. Translate the visible button face inside a stable link target. Keep keyboard focus visible.
