# Performance measurement

Headless Chromium measured the local static build on desktop 1440×900 and mobile 390×844. Navigation load events completed near 240 ms on this local server in both sessions. Browser resource transfer was 1,181,538 bytes across 30 resources. The largest resource was the locally bundled Three.js script at 670,184 bytes. After scrolling to the signature chapter and waiting 1.6 seconds, the reported JavaScript heap was approximately 5.0 MB desktop and 6.0 MB mobile. These are local synthetic measurements and do not establish real-device frame rates. Raw metrics are in artifacts/visual-validation/performance-report.json.

A later local Chromium run instrumented Largest Contentful Paint, Cumulative Layout Shift and long tasks from page start. At 1440×900 the measured LCP was 148 ms, CLS 0.0188 and one long task. At 390×844 it measured LCP 168 ms, CLS 0 and one long task. These results are from the loopback server on this computer. Input delay and real-device frame pacing remain unverified. The wordmark now caps pixel ratio at 1 on narrow or low-memory/low-core devices and pauses its animation loop completely while outside the viewport.

Frame interval sampling while the wordmark was visible initially showed 45 of 120 desktop frames above 33 ms under headless software rendering. The wordmark is fully determined by scroll progress, so its WebGL draw loop was changed to render on ScrollTrigger changes, intersection entry and resize. A repeated 120-frame sampling then measured median 16.7 ms, p95 16.8 ms, with zero frames above 33 ms at 1440×900 and 390×844. This is a synthetic headless comparison, and physical-device performance remains unmeasured.
